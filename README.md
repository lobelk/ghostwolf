# GhostWolf - Sistema de Acesso Seguro

> Um portal web seguro e moderno para gerenciamento de usuários e autenticação compartilhada.

## 📚 Documentação Completa

Para documentação detalhada, consulte:
- [`docs/README.md`](docs/README.md) - Guia de uso e instalação
- [`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md) - Como contribuir
- [`docs/LICENSE`](docs/LICENSE) - Licença MIT

## 🚀 Quick Start

```bash
# Instalar dependências
npm install

# Configurar ambiente
cp .env.example .env

# Iniciar desenvolvimento
npm run dev
```

## 📁 Estrutura do Projeto

```
GhostWolf/
├── src/                    # Código-fonte backend
│   └── server.js          # Servidor Express
├── public/                # Arquivos estáticos
│   ├── css/               # Estilos CSS
│   ├── js/                # Scripts JavaScript
│   └── img/               # Imagens e assets
├── views/                 # Páginas HTML
│   ├── index.html
│   ├── login.html
│   ├── portal.html
│   └── 404.html
├── data/                  # Arquivos de dados
│   └── users.json
├── docs/                  # Documentação
├── .env.example           # Template de variáveis
├── package.json           # Dependências
└── netlify.toml          # Configuração Netlify
```
