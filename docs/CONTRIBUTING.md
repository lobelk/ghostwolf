# 📋 Guia de Contribuição

Obrigado por se interessar em contribuir para o GhostWolf! Aqui estão algumas diretrizes para nos ajudar.

## Reportar Bugs

Antes de abrir um issue, verifique se ele já existe. Ao reportar, inclua:
- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado vs. atual
- Screenshots (se aplicável)

## Sugerir Melhorias

Ideias são bem-vindas! Por favor:
- Use um título descritivo
- Explique o caso de uso
- Liste exemplos de implementações similares
- Mencione possíveis problemas

## Pull Requests

1. Faça fork do repositório
2. Crie uma branch para sua feature (`git checkout -b feature/nova-feature`)
3. Faça commit das mudanças (`git commit -m 'Adiciona nova feature'`)
4. Push para a branch (`git push origin feature/nova-feature`)
5. Abra um Pull Request

## Padrões de Código

- Use linting: `npm run lint`
- Siga as convenções de nomenclatura
- Adicione comentários para código complexo
- Mantenha a consistência visual

## Testes

- Execute testes antes de submeter: `npm test`
- Adicione testes para novas funcionalidades
- Mantenha cobertura > 80%

## Contato

Dúvidas? Entre em contato via issues ou discussões do repositório.
